# STAMPLC_D100_SIMPLE：応答を待ってD100を表示する

FX5UのD100を同期読み取りし、LCDに`D100:1234`のように表示するシンプル版です。配線・PLC設定は[共通README](../README.md)を参照してください。

## 処理の流れ

1. UARTを初期化します。通信条件は形式5・19200bps・8E1・サムチェックあり・局番0です。
2. `plc.read_word({DeviceCode::D, 100}, d100)`で応答またはタイムアウトまで待ちます。
3. 成功したら符号付き16bit整数としてLCDとUSBログへ表示します。LCDはデバイス名も数値も3倍サイズです。
4. `delay()`で合計1秒待ち、次の読み取りへ進みます。

`read_word()`の内部で送受信と待機を処理するため、コールバック・`plc.update()`・`millis()`による周期判定は不要です。受信値は関数が戻るまでに確定するので、ローカル変数で受け取れます。

応答待ちと`delay()`の間は、このサンプルのLCD・ボタン更新も止まります。待機中も操作を処理したい場合は[非同期版](../STAMPLC_D100_MONITOR/README.md)を使用してください。

## 通信結果と自動復帰

成功時は緑LEDを約150ms点灯します。異常時はLCDに`COMM Error`を表示し、赤LEDを保持して3秒待ちます。必要に応じてUARTを再初期化し、読み取りを再試行します。初回のUART初期化失敗も再試行の対象です。詳しいエラーはUSBシリアル（115200bps）に出力します。

3秒は再試行間隔であり、遅延応答の排除を保証しません。この例は1対1接続で同じD100だけを読む表示用途です。厳密な取得時刻を保証せず、書き込みや番地切り替えへ復旧処理をそのまま流用しないでください。
